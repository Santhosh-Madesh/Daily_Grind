# Daily Grind — Project Brief

## 1. Project Overview

**Project Name:** Daily Grind  
**Project Type:** Multi-page Coffee Roastery Website  
**Industry:** Specialty Coffee / E-commerce  
**Development Stack:** React, TypeScript, Tailwind CSS v4

Daily Grind is a modern, responsive website concept for a specialty coffee roastery. The website communicates the brand's identity, showcases its coffee collection, explains its roasting philosophy, and provides clear communication channels for customers and potential wholesale partners.

The project focuses on combining an elegant visual identity with a practical, intuitive user experience across desktop and mobile devices.

## 2. Project Objectives

- Establish a consistent and recognizable digital brand identity.
- Present the coffee collection through visually engaging product cards.
- Communicate the company's sourcing, roasting, and quality standards.
- Provide an accessible contact experience for customers and wholesale enquiries.
- Deliver a responsive experience across mobile, tablet, and desktop screens.
- Demonstrate practical frontend development skills through a complete multi-page website.

## 3. Website Structure

The website consists of three primary pages.

### Home Page

- **Hero Section:** Introduces the brand with a prominent headline, supporting content, imagery, and calls to action.
- **Daily Grind Standard:** Highlights the brand's commitment to freshness, sourcing, and everyday coffee quality.
- **Product Collection:** Showcases three signature coffee products with descriptions, flavour profiles, and pricing.
- **Contact CTA:** Encourages visitors to get in touch through a dedicated call-to-action section.

### Our Coffee Page

- **Coffee Archive Hero:** Introduces the coffee collection with decorative category-selection pills.
- **Wholesale Partnership Section:** Promotes wholesale opportunities for cafes, offices, and events.
- **Coffee Collection:** Displays three coffee products with detailed product information, including roast levels, flavour notes, grind selection, package sizes, and pricing.
- **Brewing Philosophy:** Communicates the roasting approach, recommended brewing parameters, and tasting guarantee.

### Contact Page

- **Contact Form:** Provides fields for name, email address, enquiry category, and message.
- **Roastery Information:** Presents the roastery location, correspondence details, and operating hours.
- **Roastery Image:** Reinforces the brand's physical identity and atmosphere.
- **Label Section:** Highlights turnaround information, community platforms, and brand credibility.

## 4. Key Functionalities

| Feature | Behaviour |
|---|---|
| Navigation | Route-based navigation between pages |
| Mobile Navigation | Responsive navigation drawer |
| Product Favourites | Interactive toggle |
| Grind Selection | Independent selection per product |
| Package Selection | Updates selected package and displayed pricing |
| Product Enquiry | Navigates to the Contact page |
| Coffee Category Pills | Decorative active-state interaction |
| Contact CTAs | Navigate to the Contact page |
| Contact Form | Frontend validation and success feedback |
| Success Feedback | Styled confirmation popup followed by form reset |
| Community Links | External links opening in a new tab |

**Project scope:** This is a frontend portfolio project. It does not include a backend service, database, payment processing, or actual form submission infrastructure. Interactive behaviours are implemented on the frontend for demonstration purposes.

## 5. Design Direction

Daily Grind follows a modern specialty-coffee aesthetic inspired by editorial design and artisanal craftsmanship.

**Typography**
- Playfair Display — Headings and prominent editorial text.
- Plus Jakarta Sans — Body content and user-interface elements.

**Colour Palette**
- Espresso Brown — Primary brand colour.
- Caramel — Secondary accent.
- Warm Cream — Main background.
- Soft Beige — Secondary surfaces.
- Charcoal — Text and contrast.

**Design Principles**
- Clear visual hierarchy.
- Generous spacing and restrained decoration.
- Consistent design tokens.
- Subtle hover and transition effects.
- Responsive layouts with mobile-specific adaptations.
- Consistent components and interaction patterns.

## 6. Technical Implementation

| Technology | Purpose |
|---|---|
| React | Component-based UI development |
| TypeScript | Static typing and maintainability |
| Tailwind CSS v4 | Responsive styling and layout |
| React Router | Client-side routing |
| CSS Variables | Centralized design tokens |
| Inline SVG | Lightweight interface icons |

### Development Approach

The website was developed using a component-based architecture.

- Reusable components were created for shared elements.
- Individual page sections were separated into dedicated components.
- A shared layout manages the navigation bar and footer.
- Responsive styling follows a mobile-first approach.
- Centralized CSS variables maintain consistency across the design system.
- React state manages local interactive functionality where required.

## 7. Project Deliverables

- Complete multi-page responsive website.
- Reusable React component structure.
- Consistent visual design system.
- Interactive frontend elements.
- Responsive desktop and mobile layouts.
- Source code and project documentation.

## 8. Project Outcome

Daily Grind demonstrates the process of translating a visual design concept into a structured, responsive frontend application.

The project brings together interface design, component architecture, responsive development, routing, and interactive UI behaviour to create a cohesive digital experience for a specialty coffee brand.
